# Superstore Sales Analysis

## Project Overview

This project analyzes Superstore sales data using Microsoft Excel to
understand sales performance and identify important business insights.

## Objective

The objective of this project is to analyze sales trends across different
months, categories, regions, and products.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning
- Data Visualization

## Analysis Performed

- Monthly Sales Analysis
- Category-wise Sales Analysis
- Region-wise Sales Analysis
- Product-wise Sales Analysis
- Sales and Profit Analysis
- Identification of key sales trends

## Project Files

- *Superstore_Sales-PROJECT_(Sumit).xlsx* – Excel analysis and dataset
- *Superstore_Key_Findings.pdf* – Summary of key findings

## Key Skills Demonstrated

- Data Cleaning
- Excel Analysis
- Pivot Tables
- Data Visualization
- Business Insights
- Reporting

## Conclusion

The analysis provides a clear view of sales performance and helps identify
important trends and areas of business performance using Excel.
